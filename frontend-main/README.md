# frontend-main — the real Tsukuyomi Watch frontend

Owned by the frontend teammate. Build the full experience here (Living Sky dome, sumi-e dusk opening, ink-and-paper interactions) following `docs/tsukuyomi-final-guideline.md` sections 7–8.

- Reference demo of the three visual concepts: `docs/living-sky-demo.html` (open it in a browser).
- Talk to the backend through the same HTTP API that `frontend-basic` uses. `frontend-basic/src/api.ts` is a typed client you can copy.
- Backend runs at `http://localhost:8000`; OpenAPI docs at `http://localhost:8000/docs`.
